# SDG Components

Interactive playground for the Soli Deo Gloria web component library.

Build the Stencil package before starting Storybook so the custom-element loader is available:

```bash
npm run build -w @soli-deo-gloria-software/sdg-components
npm run storybook -w @soli-deo-gloria-software/sdg-components
```

Browse the **Components** stories in the sidebar to try props live.
